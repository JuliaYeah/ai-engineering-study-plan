# Study notes

每天的学习笔记，一天一个文件：`2026-11-09 Day 01.md`。

## 怎么用

时间表里每天标题下有两个链接，都在新标签页打开：

- "✎ 学习记录" - 写笔记的地方
- "📖 今日学习笔记" - 看当天生成好的笔记

1. 在学习记录里，每一项下面有一个框：每道题、Study topic、LeetCode Pattern 和练习题、网课、Hello Interview、项目、每道面试题、当天复盘
2. 输入会自动保存到 `drafts.json`，关掉页面也不会丢
3. 点 "生成今日学习笔记"，有内容的框会写进这个文件夹里当天的 `.md`
4. 在今日学习笔记里看生成的结果，日期后面有 ✓ 的是已经生成过的

## 视频链接

`videos.json` 是“视频链接”页面存的视频（主题、作者、链接），在那个页面里添加和修改，不用直接改这个文件。`video-summaries/` 里是 YouTube 视频的总结（在那个页面点“生成总结”），每个视频一个 `.md`。`authors.json` 是对作者的备注（在那个页面点作者名字展开、保存），一个作者一条。它们都和笔记一起推送和拉取。

## 随想笔记

`thoughts/` 里是“随想笔记”页面（任意页面顶部导航最后一个）存的临时想法，一个名字一个 `.md`：

1. File name 输入新名字，或者从下拉里选已有的笔记
2. 下面的框写想法，点 Update（或 Ctrl+Enter）
3. 新名字会新建一篇；已有的名字会把这条加到那篇最后，每条上面是 `## 日期 时间`

可以直接改 `.md`，比如删掉某一条，页面下次读取时就是改过的内容。`index.json` 是自动生成的笔记列表，给网页版用，不用改。它们也和笔记一起推送和拉取。

## 注意

- 改了以后再点一次生成，会用学习记录里的最新内容更新同一个 `.md`，不会多出一个文件。所以要改笔记就在学习记录里改，直接改 `.md` 的内容下次生成时会被覆盖
- 需要本地服务器（`open-study-plan.bat` 或 `start-server.bat`）；没连上时笔记先存在浏览器里，生成会改成下载 `.md`，今日学习笔记也看不了
- 时间表的 "推送到 GitHub" / "从 GitHub 拉取" 按钮会一起同步 `drafts.json` 和生成的 `.md`，在另一台设备上拉取后就能看到和继续写
- 两台设备改了不同的框会自动合并；同一个框两边都改了，以点按钮的这台为准。同一天的 `.md` 两边都生成过时保留这台的版本，在学习记录里再点一次生成就会包含两边的内容
- 这个仓库是公开的，推送上去的笔记任何人都能看到
