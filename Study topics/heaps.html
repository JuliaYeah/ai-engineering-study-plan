Key Terms

  • Heaps：堆支持快速取得最小值或最大值，适合 top-k 和调度。
  • Time complexity：输入变大时计算量如何增长。
  • Edge case：空输入、重复值等容易遗漏的边界情况。

Short Answer

For the largest k elements I keep a min-heap of size k. The root is the weakest retained candidate; a better candidate replaces it.

LeetCode 215: Kth Largest Element in an Array

O(n log k) time and O(k) space for a size-k heap.

Approach: For the largest k elements I keep a min-heap of size k. The root is the weakest retained candidate; a better candidate replaces it.

Edge cases: The heap array is not globally sorted. Validate k and define tie handling.

Reference code — reveal after your attempt
import heapq
def kth_largest(a, k):
    if not 1 <= k <= len(a): raise ValueError("invalid k")
    heap = a[:k]; heapq.heapify(heap)
    for i in range(k, len(a)):
        if a[i] > heap[0]: heapq.heapreplace(heap, a[i])
    return heap[0]
