Core Concepts

A race occurs when an outcome depends on uncontrolled execution ordering.

Interview Questions and Scripts

What invariant or contract makes your solution correct?

I identify the shared invariant and guard the entire read-modify-write operation. For a database-backed job I use a transaction or conditional update rather than a local lock. I would trace a minimal example and identify the state that must remain true after each operation.

Follow-up: Show a counterexample if that condition is removed.

What is a common failure mode?

A lock in one process does not coordinate separate workers.

Follow-up: How would you construct a regression case for it?

How would you analyze complexity?

Test interleavings with barriers; repeated success alone does not prove absence of races.

Follow-up: Which operation dominates for a large input?

How would you validate and review this implementation?

I would test the stated contract with an empty/minimal input, a boundary case and an adversarial case. I would compare the result with a simple independent implementation before optimizing. A lock in one process does not coordinate separate workers.

Follow-up: What changes if the input is untrusted or shared between workers?

import threading
class Balance:
    def __init__(self, value): self.value, self.lock = value, threading.Lock()
    def withdraw(self, amount):
        if amount < 0: raise ValueError("negative amount")
        with self.lock:
            if self.value < amount: return False
            self.value -= amount; return True
