Representative Practice

LeetCode 981: Time Based Key-Value Store

Related historical lookup problem, not a TTL implementation. Custom TTL get/put is expected O(1).

Approach: I inject a clock and treat now >= expires_at as expired. Reads lazily remove expired values; a production memory bound may require periodic cleanup too.

Edge cases: Use a monotonic clock for elapsed durations in one process; persisted wall-clock expiry has different semantics.

Reference code — reveal after your attempt
import time
class TTLStore:
    def __init__(self, clock=time.monotonic): self.clock, self.data = clock, {}
    def put(self, key, value, ttl): self.data[key] = (value, self.clock()+ttl)
    def get(self, key):
        value, expiry = self.data[key]
        if self.clock() >= expiry:
            del self.data[key]; raise KeyError(key)
        return value
